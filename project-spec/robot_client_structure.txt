Notes on additions vs. earlier draft:
- get_frame() / camera/frame is plain HTTP GET, not WS — it's a discrete request/response
  (one-shot pre-trajectory YOLO detection), not a stream.
- All telemetry timestamps ("ts") use time.monotonic() on the robot-service host, not time.time().
  Camera and joint poller share the same host clock (camera is plugged into the arm; robot-service
  is the process both run under), so their monotonic timestamps are directly comparable to each
  other. time.monotonic()'s epoch is process-relative — never persisted or compared across restarts.
- The backend does NOT generate its own timestamps for this data; it reads "ts" from the payload.
